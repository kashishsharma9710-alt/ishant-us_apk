## 🚀 How to Build & Download Android APK

This repository is pre-configured with **GitHub Actions** (`.github/workflows/build-apk.yml`) to automatically compile and release an Android APK file.

### Step 1: Push Code to this Repo
Run this command from your terminal:
```bash
git remote set-url origin https://<YOUR_GITHUB_TOKEN>@github.com/kashishsharma9710-alt/ishant-us_apk.git
git push -u origin main
```
*(Replace `<YOUR_GITHUB_TOKEN>` with your GitHub Personal Access Token from GitHub Settings > Developer Settings > Personal Access Tokens).*

### Step 2: Automatic APK Generation
Once pushed:
1. Open this repository on GitHub: `https://github.com/kashishsharma9710-alt/ishant-us_apk`
2. Click on the **"Actions"** tab.
3. You will see the **"Build Android APK for Only us"** workflow running.
4. When finished (approx 2-3 mins), click on the completed run and download **`OnlyUs-IshantAI-release.apk`** under the **Artifacts** section!
5. Or check the **Releases** tab for the latest `.apk` installer.
